# Atlas3 clients

Modern, aligned Python and R clients for **OHDSI ATLAS 3.0** and **WebAPI 3.0**.

* **Python:** `pip install atlas3`, import `atlas3`.
* **R:** `install.packages("Atlas3")`, library `Atlas3`.

Start with the repository [README](../README.md), then read:

* [Authentication and URL discovery](authentication.md)
* [Cohort definition sets](cohort-sets.md)
* [Endpoint coverage](endpoints.md)
* [Python / R parity](parity.md)
* [Architecture](architecture.md)

Both clients require ATLAS/WebAPI 3.0.0 or newer. WebAPI 2.x is rejected during
discovery.
