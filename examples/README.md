# Examples

All examples expect a live ATLAS 3.0 deployment.

```bash
# Set OHDSI_ATLAS_CLIENT_URL, OHDSI_ATLAS_CLIENT_API_KEY (via your shell or secret manager), and
# OHDSI_ATLAS_CLIENT_SOURCE in the environment before running the examples.

python examples/python-quickstart.py
Rscript examples/r-quickstart.R
```

For unit tests and package checks, no server is needed.
